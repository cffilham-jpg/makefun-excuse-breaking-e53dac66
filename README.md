## Entry

> The good news: I found the bug in 0.3 seconds. The bad news: I found it by running it on every paying customer first.

## How it works

`main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `out`), as UTF-8 bytes with no trailing newline. Run with `python3 main.py`.
